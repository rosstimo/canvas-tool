# Legacy Canvas API experiments

These files are preserved from the original `canvas-tool` working directory for reference while the new CLI is developed.

They are not the supported interface. Some contain hard-coded course IDs, duplicated environment loading, incomplete experiments, or the literal placeholder `<REMOVED_CANVAS_API_TOKEN>` where a live token was removed before the repository was published.

Use `../bin/canvas-tool` for new work. Git history preserves these experiments, so useful behavior can be migrated deliberately rather than by continuing to patch the old scripts.
